# Автоматизація запуску тестів та формування звіту

## Опис проєкту
Цей проєкт містить Bash-скрипти для автоматичного запуску модульних тестів, обробки результатів їх виконання та генерації стандартизованих звітів (текстових та HTML). 

## Підготовка до роботи
Для коректної роботи необхідні:
- Встановлений Python
- Встановлений фреймворк pytest. Встановити його можна командою:
  `pip install pytest`
- Git Bash (для користувачів Windows) або стандартний термінал Linux/macOS.

## Тестові дані (Завдання 1)
Для перевірки роботи скрипта використовується тестовий міні-проєкт на Python у каталозі `sample_py/`.
Стандартна команда для ручного запуску цих тестів (без збору артефактів): ```bash
python -m pytest -q sample_py/
