# Навчальний проєкт з CI/CD

Цей репозиторій містить налаштований мінімальний сценарій CI/CD за допомогою GitHub Actions. Конфігурація пайплайну знаходиться у файлі: `.github/workflows/ci.yml`.

## Локальний запуск скриптів
Усі етапи CI можна відтворити локально (наприклад, у Git Bash). Переконайтеся, що ви знаходитесь у корені репозиторію.

1. **Setup (Підготовка):**
   Виконайте `bash scripts/setup.sh` для встановлення залежностей.
2. **Test (Тестування):**
   Виконайте `bash scripts/test.sh`. Після запуску результати тестування з'являться у файлі `reports/test_output.txt`.
3. **Build (Збірка):**
   Виконайте `bash scripts/build.sh`. Файл з інформацією про збірку з'явиться за шляхом `artifacts/build_info.txt`.

Примітка: Каталоги `reports/` та `artifacts/` генеруються автоматично під час роботи скриптів і не зберігаються у системі контролю версій.
